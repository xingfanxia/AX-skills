# Verification Notes

This file records reproducible local checks. Live PhotoKit validation has not been performed.

## 2026-07-20

- **Infrastructure**: Normalization via read-only `osxphotos==0.76.1` and native PhotoKit process bridge are operational.
- **Namespaces & State**: Isolated osxphotos and PhotoKit identifier namespaces, sorted asset-ID-set snapshots, strict manifests, metadata preconditions, fail-fast per-item transaction evidence, and durable receipts are implemented.
- **Verification**: Verified `ruff check .`, 172 synthetic Python tests, and 18 offline Swift tests. Tests cover the fixed native trust anchor, dual replay prevention, signed planner/token envelopes, strict single-photo resource coverage, bounded delete evidence and mutations, native-boundary source drift, exact mutation phases and verification records, power-loss-durable receipts, and import transaction isolation. No test accesses real Photos libraries.
- **Pixel Delete Contract**: Pixel comparison is the sole supported deletion evidence for byte-different, single-resource still-image pairs. Planning replays the frozen comparison, enforces the canonical threshold ceilings, rejects compound or partially available assets, verifies candidate and keeper input hashes belong to current PhotoKit resources, and seals the complete canonical planner claims with a local HMAC. The human token binds those claims, and the native helper verifies both signatures and repeats source ownership hashing before mutation. SHA-256 is an integrity and ownership binding only, never an equality gate. Byte-identical duplicate deletion is unsupported.
- **Continuous Integration**: Added GitHub Actions coverage for Python 3.11/3.12 Ruff and pytest checks, package builds, and macOS Swift release tests. Live Photos access remains excluded from CI.
- **AI Agent Authorization Guard**: The `delete authorize` TTY prompt now prints an explicit instruction telling AI agents to stop and obtain the most recent and explicit human authorization before entering the confirmation phrase. Piping or PTY-injecting the phrase without human confirmation violates this guard. A unit test verifies the guard text is present in every authorize prompt.
- **Live Mutation Lessons**: PhotoKit permission may require TCC reset or manual System Settings configuration. osxphotos UUIDs and PhotoKit local identifiers are separate namespaces; use `asset mutation-list` for authoritative discovery. `date_taken` from osxphotos may differ from PhotoKit's UTC time due to import-time contamination; do not use `date_taken` as identity evidence. These lessons are codified in the skill's Known Limitations section.
- **Delayed System Confirmation**: A live 1,690-item delete under the former 300-second deadline appeared to time out because macOS was waiting on a Photos deletion confirmation window while the operator was away. After the operator later approved the still-visible prompt, fresh reconciliation found all 1,690 candidates absent through PhotoKit and present in Recently Deleted through osxphotos. The client deadline has therefore been removed specifically for delete dispatch, keeping the process and library lock alive while confirmation is pending. Any external interruption still yields an unknown outcome that must never be retried automatically.
- **Delete Precondition Optimization**: Delete apply no longer performs the same per-asset descriptor validation twice in Python. The Swift helper performs the single authoritative expected-state validation at the native mutation boundary, checks token expiry again, and then enters one `performChangesAndWait` transaction. This retains fail-closed target drift detection while avoiding repeated Python-side `fetch_assets` work. Helper responses distinguish precommit rejection from post-dispatch uncertainty; any uncertain result still requires fresh read-only reconciliation and must not be auto-retried.
- **Library Tracking**: Public PhotoKit does not expose System Photo Library paths or physical identity. Snapshot equivalence does not prove physical library identity.
- **Packaging**: Verified wheel/sdist builds and isolated Python 3.12 wheel installation. The wheel packages schemas, the skill, documentation, and Swift helper source. The `apple-photos helper-source` command successfully locates helper source and emits structured `build_argv` arrays for compiling.
- **Security Gates**: Verified the AST SQL scanner blocks dynamic SQL, `executescript` with `DELETE` or `VACUUM`, unrecognized SQLite execution APIs, and statements outside the replay-ledger allowlist. Publication privacy scans passed.
